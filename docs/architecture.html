Scrapers built by Devin, checked by code

Shelvin architecture

Shelvin (shelf + Devin) scans a product and finds the brand's own site first, then Mexican retailers. When a site has no scraper, Devin writes one, code checks it, and the app shows every step. Sites that refuse AI agents are listed, never scraped.
